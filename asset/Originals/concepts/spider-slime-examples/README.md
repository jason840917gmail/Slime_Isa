# Spider Slime Concept Examples

Three generated concept directions based only on the project's non-spider slime artwork:

- `forest-orb-weaver-slime.png` — lime-green woodland variant with leaf sprout and web markings.
- `crystal-web-slime.png` — cyan/lilac cave variant with suspended web geometry and crystal growths.
- `ember-tarantula-slime.png` — molten-orange heavy variant with rounded dark-tipped legs.

These are concept illustrations, not production sprite sheets.

The forest orb-weaver direction became the runtime spider
(`asset/MAPS/enemies/64x64-8x10-forest-orb-weaver-slime.png`, `character.enemy.slime-spider`).
