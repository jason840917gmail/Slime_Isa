# Sword Attack Video Prompt — Side → Up → Down

Attach the sword reference image before using this prompt.

```text
Using the attached sword reference, create one short one-shot sword attack
animation in modernized pixel-stylized top-down 2D game art. Show only the
sword. Preserve its exact blade, guard, grip, pommel, colors, proportions, and
identity throughout the video.

Keep the sword perfectly centered at the same screen position and scale for the
entire video. Use a fixed top-down game camera: no zoom, pan, tilt, rotation,
shake, cuts, transitions, or perspective changes. Use a completely flat solid
chroma-purple background #8000FF with no grid lines, dividers, scenery, text,
or other objects.

Create one continuous silent, non-looping sequence in this
exact order:

1. Side attack facing right: ready pose, wind-up, swing/contact, follow-through.
2. Brief neutral reset while staying centered.
3. Up attack: ready pose, wind-up, swing/contact, follow-through.
4. Brief neutral reset while staying centered.
5. Down attack: ready pose, wind-up, swing/contact, follow-through, then finish
   in a stable neutral pose.

Keep each attack clearly separated; never blend two directions in one swing.
Use smooth readable motion, stable sword design, and restrained slash effects
that stay fully visible. No extra weapons, character, UI, scenery, photorealism,
glossy 3D rendering, or motion blur.
```

After generation, extract the key frames from each directional section and
arrange them into separate 6-frame rows: side, up, down.
