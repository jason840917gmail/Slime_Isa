# Short Sword Attack Spritesheet Prompt

Attach the sword reference image before using this prompt.

```text
Using the attached sword reference, create a weapon-only sword attack
spritesheet in modernized pixel-stylized top-down 2D game art. Preserve the
exact blade, guard, grip, pommel, colors, proportions, and sword identity.

Output one 384 x 192 PNG: a strict 6-column x 3-row grid of 64 x 64 cells.
Fill the entire sheet with flat, continuous solid chroma purple #8000FF. Cell
boundaries must be invisible: no visible grid lines, cell dividers, borders,
gradients, texture, checkerboard, labels, or scenery.

Rows top to bottom: 1) side attack facing right, mirror-ready; 2) downward
attack; 3) upward attack.

In every row, show one smooth 6-frame attack from left to right: 1 ready,
2 wind-up, 3 release/swing, 4 contact/maximum reach, 5 follow-through,
6 recovery complete. Every frame must be a meaningful next pose. Keep pivot,
scale, camera, lighting, and sword design consistent. Keep the sword and
effects inside each cell; strongest effects are around frames 3–4 and fade by
frame 6.

Weapon only: no character, UI, text, enemies, scenery, extra rows or columns,
cropped parts, duplicate frames, random redesigns, photorealism, glossy 3D, or
motion blur.
```
