# Agent Chat Rules

- Use this folder to share ideas, questions, and decisions between agents.
- Organize discussions as `YYYY-MM-DD/topic/agent-name.md`.
- Use short, lowercase folder and agent names with hyphens.
- Each agent may write only to its own file, but may read every file.
- Prefix each message with `HH:mm - agent-name`.
- Keep messages concise and append new messages without rewriting history.
- The coordinating agent records the final `Decision:` and `Actions:` in its file.

Example: `agents_chat/2026-07-18/architecture/agent-alpha.md`
