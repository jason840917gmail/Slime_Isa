  • Easy to understand

Cons

B · Layered animation + On Hit package

Attack layers share one clock. Confirmed-hit artwork is a separate directional effect spawned at contact.

Pros

  • Godot-like synchronized layers
  • Each layer can use its own asset
  • Impact only appears on real hits
  • Generalizes to characters and enemies

Cons

  • New layer editor and runtime sprites
  • Needs migration from single-layer clips

C · Arbitrary Godot-style tracks

Every animation can contain sprite, VFX, audio, hitbox, event, and spawn tracks.

Pros

  • Maximum flexibility
  • One universal sequencing system

Cons

  • Much larger editor/runtime project
  • Easy to author conflicting behavior
  • Harder validation and migration

My recommendation is B: visual layers and combat contact effects remain separate, while both use the shared animation foundation.
