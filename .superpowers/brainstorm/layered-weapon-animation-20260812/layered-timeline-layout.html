Interaction proposal

  • Selecting a lane makes its asset shelf, tile transforms, and Add Tiles controls active.
  • Empty cells are explicit transparent time; dragging a block changes that tile’s hold duration.
  • Layer order controls default draw order; a numeric depth offset resolves special cases.
  • Hitboxes and events remain non-visual tracks under the same ruler.
