Weapon timeline: choose the time model

The source sheet becomes a picker opened from Add Tiles. The animation timeline stores tile occurrences with explicit duration, so one sword tile can hold for five frames without duplicating it. Click the direction that matches what you want the editor to feel like.

A · Godot-style duration blocks recommended

Separate the visual tile track from time. Each tile block has a start and duration; dragging its right edge changes how many animation frames it holds.
