# Consolidated ideas — 2026-08-22

## Status

Triaged and routed into the active roadmap and open task specifications. This
file is now a decision record, not a second backlog.

## Consolidated direction

### Player action dashboard and equipment

Merge the six-slot weapon/tool belt and ability bar into one responsive bottom
dashboard. Weapon assignment supports both drag/drop and an **Equip to slot
1–6** control, with both paths using the existing loadout authority. Ability
slots remain fixed in the first version.

Owner: [Player action dashboard and loadout assignment](./open/player-action-dashboard-and-loadout.md)

### Full player map and visual map organization

The player’s full world map and Map Studio’s all-map organizer are two views of
one authored world graph. Map Studio will show draggable map previews and
cardinal connector ports; the player map will show discovery and travel context.
Neither surface owns a separate list of neighbors.

Owner: [Shared world map and Map Studio graph](./open/global-map-and-map-joining.md)

### Crafting, food, and farming

Refactor the existing crafting popup around one recipe catalog filtered by
unlock state, station family, and station tier. Use the official station names
**Workbench**, **Forge**, **Kitchen**, and **Alchemy Table**. Food progresses
from foraging to one persistent crop loop and then Kitchen recipes.

Owner: [Station-aware crafting, food, and starter farming](./open/station-aware-crafting-food-and-farming.md)

### First stone-age level

Replace temporary automatic starter-item grants only after safe hand-collectible
wood and stone exist. The player crafts a Wooden Spear, Stone Axe, Stone Pickaxe,
and Stone Spear, clears a small guarded encounter, opens a reward chest, and
uses its persistent green key to unlock the next authored area.

Owner: [Starter stone-age progression](./open/starter-stone-age-progression.md)

## Resolved duplicates and inconsistencies

| Earlier note | Resolution |
|---|---|
| Separate weapon dashboard and ability dashboard | One visual dashboard, separate existing gameplay authorities |
| Drag/drop versus slot dropdown | Both are supported and call one assignment command |
| Work table / Workbench | **Workbench** |
| Foundry / Forge | **Forge** |
| New crafting popup | Refactor and reuse the existing `CraftingUI` |
| Full world map and editor map organizer | Two views of one validated authored graph |
| “Wood axe” requiring wood and stone | Renamed **Stone Axe** |
| Start with no weapons despite current automatic grants | Remove grants only after the replacement progression is softlock-safe |
| “Defeat the enemies and the box” | Enemies guard a reward chest; the chest is not an enemy |
| First crafting table versus later home Workbench | Starter recipes are portable; the home Workbench retains advanced station recipes |

## Roadmap routing

- Milestone 2 owns starter materials, recipes, tool gates, and the green-key
  progression proof.
- Milestones 5, 8, 9, and 10 own Workbench, Forge, Kitchen, and Alchemy content.
- Milestone 9 owns the first forage → farm → cook loop.
- Cross-cutting UX owns the combined action dashboard and loadout assignment.
- Cross-cutting world authoring owns the shared world graph, Map Studio organizer,
  and player-facing full map.
