# Terrain And Tile Guide

Ground tiles, tile physics, walls, and floor decorations.

## Grid contract

- World tile size: `64 x 64 px` (map `tileSize`).
- Each authored map owns its size; most production maps are `54 x 54` tiles
  (`3456 x 3456 px`), level-1 is `56 x 56`, interiors are smaller.
- Terrain is ground only. Maps store one logical tile ID per cell.

## Ground sheets

Each outdoor ground material is one `1216 x 1216` sheet: `19 x 19` cells of
`64 x 64`, in `asset/MAPS/grounds/64x64-tile_19x19_<ground>.png`, registered as
`sheet.grounds.19x19.<ground>`.

- Sources: large generations (2048 px) in `asset/Originals/grounds/generated/`
  and the original sheets in `asset/Originals/grounds/legacy-sheets/`.
- `pnpm grounds:pack` grades them and makes each sheet wrap-seamless (right edge
  continues into left, bottom into top). `-- --only <sheet>` packs a subset.
  Needs Python with Pillow and numpy.
- The tile set repeats the sheet with `selection: "sheet-wrap"`, so a large
  area shows no mirror seams or repeated single tile.
- Keep ground art low-contrast and even: blending between materials and
  decorations supply the variety.

Interior floors are single `128 x 128` squares (`terrain.interior.floor-*`)
picked per cell with `selection: "seeded-hash"`; make them tile seamlessly
against copies of themselves.

## Tile set

Tile IDs, their sheets, and their physics live in the shared `terrain.tiles`
resource (`src/game/content/scenes/authored/resources/terrain/terrain.tile-set.resource.json`),
edited in Scene Studio; `content/terrain/TileCatalog.ts` reads it. Per tile:

- `assetIds` and `selection` (`sheet-wrap`, `seeded-hash`, `sheet-order`, `ground-sheet-region`);
- `physics`: `null` for walkable ground, or `{ "body": "static", "inset": {...}, "layer": "water" }`.
  Missing inset sides default to left/right `6`, top/bottom `8`;
- `allowsDecorations` and `tags`;
- optional `transition` (`group: "natural-ground"`, `material`, `priority`):
  higher priority blends into lower. Blending is visual only; see
  [Terrain Transitions](../TERRAIN_TRANSITIONS.md).

A new ground material needs: source art, a `grounds:pack` entry, a manifest
entry, and a tile in `terrain.tiles`.

## Walls

Cave and forest walls are not tiles. They are placed object instances of wall
prop scenes (`object.crystal-cluster-wall.*`, `object.tree-forest-wall.*`)
generated by `python scripts/props/generate-wall-prop-scenes.py` from the
crystal cluster sheet (`pnpm props:pack` builds it from
`asset/Originals/props/`) and the tree sheet. Each prop has a `48 x 44`
footprint on the 64 px grid, so a run of props stays a solid barrier while the
art varies through per-instance `visualOffset`/`scale` overrides. Stone and
rock walls use the `wall-stone-solid` and `rock-world-wall-*` scenes.

## Floor decorations

Leaves, twigs, pebbles, moss, and small mushrooms are walk-over decal scenes
(no body, `depthBand: "ground-decals"`). Scatter them over forest grounds with
`node scripts/maps/scatter-decorations.mjs <world-id>... [--write]`.

## Authoring tips

- Test a ground sheet by tiling it 2 x 2 before packing.
- Compare props against a `64 x 64` tile mockup, not in isolation.
- Keep collision footprints aligned with the base of the art players feel.
